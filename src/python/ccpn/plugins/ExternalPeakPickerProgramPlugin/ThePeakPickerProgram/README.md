# UCSF Peak Picker Demo

## Notice

This program is **only** a demonstration to showcase how an external program can be linked and run, exchange data via files, and update a display in real time with CcpNmr Version 3.

It is **not**:

- A general-purpose NMR data visualisation tool
- A reliable or maintained application
- An example of best practices for GUI or scientific programming
- A recommended approach for peak picking, data processing, or file watching

All code is **hard-coded** for demonstration purposes and may lack error handling, flexibility, or performance optimisations.
It is **not maintained** nor enhanced, **no future requests allowed**, **do not expect documentation**.


## How to Use

```bash
./DemoPeakPicker.sh GB1_HSQC.ucsf GB1_peaks.csv
```

Make sure DemoPeakPicker.sh is executable: 

```bash
chmod +x DemoPeakPicker.sh
```
